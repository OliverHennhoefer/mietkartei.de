# Geist

Die unveränderte variable Schriftdatei `Geist.ttf` stammt aus dem [Google-Fonts-Verzeichnis](https://github.com/google/fonts/tree/main/ofl/geist) und wurde dort am 18. Oktober 2026 als `Geist[wght].ttf` heruntergeladen. Sie enthält Geist Version 1.800, entworfen von den [Geist-Projektverantwortlichen](https://github.com/vercel/geist-font).

- [Originaldatei](https://raw.githubusercontent.com/google/fonts/main/ofl/geist/Geist%5Bwght%5D.ttf)
- SHA-256: `73894e0448cae90a92b6c2f8732b7bb9acb7b94c418bff559dad4a18e1de9659`
- Lizenz: [SIL Open Font License 1.1](OFL.txt), mit unverändertem Urheberrechtsvermerk
- Verwendete Einstellung: `wght = 500` (Medium), native Laufweite und Kerning

Die Wortmarken enthalten ausschließlich Konturen der verwendeten Buchstaben. Die Schriftdatei bleibt als Quelle für reproduzierbare Exporte erhalten.

`Geist.woff2` ist dieselbe Schrift, nur ohne Änderung an den Glyphen ins kleinere WOFF2-Format umgewandelt (mit fontTools). App, Website und Dokumentation laden diese Datei, 70 statt 169 KB.
